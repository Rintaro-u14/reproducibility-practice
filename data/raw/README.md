# 生データ（data/raw）

生データを `sub-XX/ses-YY/` の形のまま、ここにコピーします。

- データの本体はGitに入れません（`.gitignore` で最初から外してあります）。
- `uv run dvc add` で登録するとできる `sub-XX/ses-YY.dvc`（目印のファイル）だけを、Gitで記録します。
- 置いたあとは書き換えません。

## データの中身

架空の脳波です（実在する人のデータではありません）。被験者3人（sub-01〜sub-03）× 測定2回（ses-01、ses-02）。

| ファイル | 中身 |
|---|---|
| `sub-XX_ses-YY_eeg.csv` | 1列目が時刻（秒）、2列目からが8チャンネル（Fz, C3, Cz, C4, Pz, O1, Oz, O2）の電位（µV）。1秒あたり250点、120秒分 |
| `sub-XX_ses-YY_events.csv` | 区間の記録。目を開けた区間（`eyes_open`）と閉じた区間（`eyes_closed`）が10秒ずつ交互に並ぶ |
